One description, changing distance

Each example uses one fixed text description, shown below. Hyper3-CLIP encodes it as a point in hyperbolic space. The slider moves that query point closer to or farther from the origin along the same direction.

At each position, every image in the gallery is ranked by the hyperbolic distance between the query point and that image; the nearest come first.

CLIP ranks the same gallery by cosine similarity to its own encoding of the description, so its results stay fixed for a given example. A Haystack pipeline coordinates both: it loads the gallery, encodes the description with each model and passes the results to rankers that apply each model's own scoring.

The Haystack pipeline computed results for all 101 slider positions of each example beforehand. Moving the slider displays those results without running new model inference.
